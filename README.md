# Калькулятор ДомСтрой

Веб-калькулятор для строительной компании «ДомСтрой» (Аксай, Ростов-на-Дону, Батайск): стоимость дома по площади и варианту готовности, материалы для ремонта, подбор кабеля под технику и платёж по ипотеке.

**Открыть:** https://pochuvstvuyvkus.github.io/domstroy-calculator/

## Что считает

| Раздел | Что на выходе |
|---|---|
| Стоимость дома | Цена по трём вариантам: Стройвариант 54 000, Чистовая 64 000, Под ключ 92 000 ₽/м²; срок, первый взнос, платёж по ипотеке |
| Комната | Пол, периметр, стены за вычетом проёмов, площадь откосов |
| Санузел | Плитка на пол и стены, клей, затирка, крестики, грунт, гидроизоляция |
| Плитка · Ламинат · Обои · Краска · Штукатурка · Потолок | Количество материала с запасом и расходники |
| Фундамент и стены | Бетон, арматура, газоблок, облицовочный кирпич |
| Электрика | Кабель, автомат и УЗО под каждую единицу техники, проверка лимита мощности |
| Ипотека | Платёж по программе, лимит по числу детей, платёж после 15 лет |

Размеры комнаты запоминаются и подставляются в остальные калькуляторы.

## Как устроено

Одна страница без сборки и зависимостей: `index.html` содержит разметку, стили и скрипт. Шрифты — Google Fonts. Светлая и тёмная темы, адаптив от 375 px.

Заявка в демо-версии никуда не отправляется — форма показывает собранные данные и говорит об этом прямо. В рабочей версии заявки уходят менеджеру в Telegram и в Google Таблицу.

## Правки

Цены, ставки и нормы расхода лежат в начале скрипта: `TIERS`, `PROJECTS`, `TILES`, `POWER`, `PROGRAMS`, `LIMITS`. Меняются там же, без пересборки.

Расчёты примерные и не являются офертой.
